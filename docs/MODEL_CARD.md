# 130U-FinLLM-24M：模型规格与训练状态

这是模型规格与阶段性训练记录；尚未发布正式任务权重或金融立场性能报告。

- **任务：**英文短文本对指定股票或资产的 bearish / neutral / bullish 立场。
- **架构：**约24.26M参数、自回归Dense Transformer、自建8K byte-level BPE。
- **权重起点：**随机初始化；主训练不加载其他模型预训练权重。
- **输出：**三类归一化概率、`100*(p_bullish-p_bearish)`、最大类概率和复核状态。
- **输入边界：**目标明确可核验；默认512-token上下文，超长返回复核；处理单文本单目标，多目标由调用者展开。
- **预训练计划：**100M通用、25M金融混合累计tokens；完整预算的数据和revision待取得并审核。
- **后训练计划：**全参数SFT、DPO实验、独立温度与阈值校准。
- **扩充阶段入口：**01b 复用原词表、排除 seed／任务文本并建立独立数据版本；02c 冻结 seed 母检查点，仅承接权重并重新建立阶段优化状态。用户日志确认该阶段已到 610 步。02d 保留完整 610 步成果后严格恢复优化器／调度器／随机状态／游标，目标扩充阶段累计 1220 步。原验证分片保持冻结，续训比较独立保存；02d 的新 Colab 段尚未执行，见 [续训说明](EXPANDED_CONTINUATION.md)。
- **评估状态：**工程用合成样本检查已完成；2026-10-11 用户提供的日志及备份输出确认真实通用语料 T4 预训练先完成 seed 的 300 步／4,914,941 有效 tokens，再完成扩充阶段 610 步／9,994,240 tokens，模型路径累计 14,909,181 个监督位置。新验证子集 loss 4.1311，原 seed 保留子集训练后 loss 4.4032；最终快照输出校验通过，见 [扩充记录](../reports/colab_t4_expansion_20261011.json)。未独立下载云端权重验证，也没有提供本轮 retention-before 数值。尚未完成长期预算、真实任务后训练或金融立场准确率评估。
- **局限：**目标关系由保守输入规则检查；语言与域外识别并不完备；反讽、引述和隐含资产关联须人工审核。分数不能解释为股价上涨概率、未来收益或情绪强度回归真值。
