# 130U-FinLLM-24M：模型规格与待训练模型卡

这是预先登记的模型规格，不是已发布权重的性能报告。

- **任务：**英文短文本对指定股票或资产的 bearish / neutral / bullish 立场。
- **架构：**约24.26M参数、自回归Dense Transformer、自建8K byte-level BPE。
- **权重起点：**随机初始化；主训练不加载其他模型预训练权重。
- **输出：**三类归一化概率、`100*(p_bullish-p_bearish)`、最大类概率和复核状态。
- **输入边界：**目标明确可核验；默认512-token上下文，超长返回复核；处理单文本单目标，多目标由调用者展开。
- **预训练计划：**100M通用、25M金融混合累计tokens；正式数据和revision待取得并审核。
- **后训练计划：**全参数SFT、DPO实验、独立温度与阈值校准。
- **评估状态：**工程用合成样本检查已完成；2026-10-11 用户截图确认 24M 模型在真实语料上完成 T4 的 999,424-token 预训练试跑并备份，见 [试跑记录](T4_PILOT.md)。尚未完成长期预训练、真实任务后训练或金融立场准确率评估。
- **局限：**目标关系由保守输入规则检查；语言与域外识别并不完备；反讽、引述和隐含资产关联须人工审核。分数不能解释为股价上涨概率、未来收益或情绪强度回归真值。
- **代码来源：**MiniMind固定版本的结构参考，见THIRD_PARTY_NOTICES；新项目代码Apache-2.0。
- **数据/权重许可：**正式数据接入后逐来源核查；不能将代码许可证直接套给以后训练出的全部权重或语料。

正式训练后补全：代码/数据/tokenizer哈希、计算环境、各阶段tokens与实际耗时、对照模型、三类指标和误差切片、校准效果、适用范围与剩余问题。
