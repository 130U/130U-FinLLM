# 130U-FinLLM：后训练与量化成果的快速方案

## Charter

- **目标**：在已有 24M 参数模型上，保留现有训练成果，给出可执行的后训练及评估顺序，并报告真实可复现的量化结果。
- **范围／对象／主题**：英语金融文本分类／已有模型的资产目标立场／类别平衡 SFT、可选 DPO 和未见数据验证。
- **研究类型**：描述性；项目有具体训练记录，需要限定下一实验的条件与成果。
- **问题**：Q1 如何处理类别失衡；Q2 DPO 需要什么数据；Q3 如何判断新模型；Q4 是否可使用外部推特金融数据。
- **证据路径**：优先原始论文、原始数据集卡和官方文档；项目日志及代码记录该项目的实际行为。检索日期 2026-10-31。

## Scope filter

不将 F2 从教育对话任务泛化成金融文本的保证效果；不将文本情绪或新闻标题分数解释成未来收益或已验证的证券代码表现。

## Object filter

F1 仅为训练过程中反复使用的、非时间切分开发集结果；之前已经查看的旧测试集不能作为新模型的全新独立测试。F5 的整条文本标签不自动等于文中每一个资产的独立立场；多资产或目标不明确的内容需排除或单独标注。数据集卡列出的许可仍需结合实际来源及使用方式判断，且应先核对真实行数。

## Conclusions

1. **固定当前已选出的平衡 SFT 检查点，先完成独立评估和可用推理演示**；比较 macro-F1、各类召回及原模型／简单基线，不从开发集成绩推断实际推特表现（F1、F4）。
2. 若确需展示 DPO，可考虑只从训练集中以已确认正确标签和错误标签构造派生的 `chosen/rejected`，冻结 SFT 参考模型，做有界对照；必须称为**从类别标签派生的偏好**，而非新增人类偏好，并保留可能更好的 SFT（F3）。目前 formal DPO 检查每对均为 `preference_reviewed=true`；类别标签确认并不意味着偏好对逐对审过，不能伪填该字段。必须先实现明确区分派生对的独立探索流程，或先完成人工偏好审核。这是一项未实施的探索方案，不保证提升。
3. 外部推特数据可作为候选，但需先固定版本、核实可用性、许可和标签语义；仅在明确单一目标且标签适配时作为弱监督候选，多目标和不清楚方向的样本不得默认为真实资产立场（F5）。
4. 校准应在选定模型后用独立校准分区进行；单靠校准不能改变模型类别排序（F6）。

## Next steps / Risks

1. 核验并永久保存新 SFT 最佳检查点、词表、代码版本及输出；日志中备份已生成，不等于已经下载。
2. 若进行 DPO：先固定数据和训练预算、严格排除评估分区，以同一开发集比较 DPO 与 SFT；不使用反复查看过的旧测试结果声称最终效果。
3. 准备来源合法且未用于训练、调参的新测试集；按目标资产、事件和时间审查，记录每类样本量、宏 F1、各类召回和拒判覆盖率。若新数据或标注尚不可得，明确为未完成，不制造结果。
4. 今日可交付包括可复现代码、真实的开发集对照、保存的检查点和演示；实际预测可靠性、推特域迁移及投资收益仍未建立。
